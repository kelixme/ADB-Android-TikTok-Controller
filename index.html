Управляйте TikTok прямо с ПК

Пауза, лайки, избранное и прокрутка ленты — без касания экрана телефона. ADB TikTok Controller связывает ваш Android с ПК через ADB + scrcpy и превращает клавиатуру в полноценный пульт управления.

Как работает

Телефон + scrcpy = пульт управления

1
Включите отладку по USB

На Android разрешите «Отладку по USB» и установите ADB-драйверы.

2
Подключите устройство

По кабелю или Wi-Fi — приложение само найдёт телефон.

3
Откалибруйте кнопки

Настройте координаты под экран устройства за пару секунд.

4
Управляйте

Используйте кнопки интерфейса или горячие клавиши.

Установка

Три способа запустить

Python 3.8+, Android с отладкой по USB — и вперёд.

🐍 Из исходников

  • Python 3.8+ уже установлен
  • Установите зависимости и запустите
> pip install -r requirements.txt > python app.py

📦 Готовая сборка

  • Ничего устанавливать не нужно
  • Собранный exe + все библиотеки (adb, scrcpy) в одной папке
  • Конфиг хранится рядом с exe — перенос не ломает настройки
ADB-TikTokControllerProtable.zip
